# Portfolio — Rocío Fernández Doval

Primera versión del portfolio personal, desarrollada en HTML, CSS y JavaScript para publicar con GitHub Pages.

## Archivos
- `index.html`: estructura y contenidos.
- `style.css`: diseño adaptable a pantallas grandes y móviles.
- `script.js`: filtros de proyectos y menú móvil.

## Antes de publicar
1. Reemplazar el enlace `mailto:` del pie por el correo de contacto.
2. Revisar fechas y descripciones de la trayectoria.
3. Revisar los enlaces externos y decidir si querés sumar otros trabajos.
4. Si querés, cambiar la tipografía o los colores en las variables de `style.css`.
